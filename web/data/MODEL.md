# Pronunciation model and phonetic reference

Faseeh uses the phoneme head of Quran Muaalem v3.2, the pretrained multi-level CTC model by obadx, without fine-tuning. The model revision is `01a1ef9fbe40d144ef845101e89ff924aed3fef5`. The weights download to the operator’s model cache. [Model card](https://huggingface.co/obadx/muaalem-model-v3_2) · [Quran Muaalem](https://github.com/obadx/quran-muaalem)

Quran Muaalem’s Python package includes the Quran Muaalem License v1.0. Its AI advisory is displayed before recording and is available in the reader. Providers building a different interface for the API must display the advisory before first use and keep it accessible afterwards, in Arabic and every interface language. [License](licenses/Quran-Muaalem-LICENSE.txt) · [Upstream notices and translations](https://github.com/obadx/quran-muaalem/blob/main/NOTICE)

The reference script and letter mappings come from Quran Transcript 0.6.1 and its Tanzil Uthmani text. The lookup file represents joining words within an ayah and stopping at its end. Special phonetic symbols represent recitation features including qalqalah, nasalization and long vowels. Use `python tools/build_phonetics.py` with the model dependencies installed to reproduce it. [Quran Transcript](https://github.com/obadx/quran-transcript) · [Tanzil Project](https://tanzil.net/) · [License and text attribution](licenses/Quran-Transcript-LICENSE.txt)

The recognizer emits phonetic symbols and their timing from the recording. The API aligns them to valid reference pronunciations from the selected starting ayah and counts each affected word once. The timing is an estimate of speech recognition boundaries. Results reflect model predictions. Empirical examples and automated checks cannot certify the recitation or all articulation features. The ten sifat classifier heads are compared on recognized words only when acoustic event counts and times support a one-to-one match with the phoneme groups. Ambiguous attribute events are omitted. A qualified teacher should assess the learner and independently validate the educational materials.
